# Reel Studio — plan-driven vertical reel generator

Programmatic 1080×1920 / 30fps how-to reels in the warm-amber `@alex.snippet`
style. Every reel is described by a JSON **plan**; the same renderer turns
any plan into a polished MP4. Plans can be hand-written or generated by
Claude from a one-line topic.

## Quick start

```bash
cd video
npm install
npm run dev                          # studio: live preview of every plan
```

### Make a brand-new reel from a topic

```bash
ANTHROPIC_API_KEY=sk-… \
ELEVENLABS_API_KEY=…   \
  npm run create -- "How to install Cursor in 30 seconds"
```

The CLI:
1. Asks **Claude** to write a plan JSON for that topic.
2. Pauses so you can edit the plan if you want.
3. Generates a voice-over via **ElevenLabs** (or OpenAI TTS as a fallback).
4. Renders the final MP4 to `out/<plan-id>.mp4`.

Skip steps with flags: `--no-edit`, `--no-tts`, `--no-render`.
Reuse an existing plan with `--plan plans/<id>.json`.

### Render an existing plan

```bash
npm run render -- src/index.ts setup-claude-code out/setup-claude-code.mp4
```

## Plan schema (high level)

```jsonc
{
  "meta": {
    "id": "kebab-case-id",
    "title": "Setup Claude Code",
    "subtitle": "in 30 seconds",
    "language": "en",            // or "he" for Hebrew RTL captions + voice
    "voiceId": "<eleven-labs-voice-id>",
    "fps": 30
  },
  "scenes": [
    { "type": "title",    "id": "...", "durationSeconds": 5,  "narration": "...", "title": "...", "subtitle": "..." },
    { "type": "browser",  "id": "...", "durationSeconds": 6,  "narration": "...", "url": "...", "content": { "kind": "google", "query": "vs code" }, "cursorPath": [...] },
    { "type": "desktop",  "id": "...", "durationSeconds": 7,  "narration": "...", "contextMenu": { "openAt": 0.9, "highlightIndex": 0 }, "cursorPath": [...] },
    { "type": "terminal", "id": "...", "durationSeconds": 5,  "narration": "...", "lines": [...] },
    { "type": "code",     "id": "...", "durationSeconds": 4,  "narration": "...", "filename": "...", "code": "..." },
    { "type": "outro",    "id": "...", "durationSeconds": 2,  "narration": "...", "bigText": "Done.", "smallText": "Follow for more" }
  ],
  "captions": [
    { "text": "vs code", "at": 6.6, "hold": 0.75, "y": 920, "rotation": 3 }
  ]
}
```

Full Zod schema lives in `src/types/plan.ts` — that's the single source of
truth and Claude is told to obey it.

### Scene types

| type       | purpose                                                                 |
| ---------- | ----------------------------------------------------------------------- |
| `title`    | Opening card with stylised desk illustration + animated title           |
| `browser`  | Chrome window. Content is `google` SERP, the `vscode` site, arbitrary `custom` HTML, or a Playwright `recording` |
| `desktop`  | macOS desktop with optional right-click context menu and animated cursor |
| `terminal` | Typing terminal that emits lines on a timeline (pretend installs, runs) |
| `code`     | VS-Code-style editor card with light syntax highlighting                |
| `outro`    | Closing card                                                            |

Every scene supports `cursorPath` (array of waypoints) so you can show
exactly where to click.

## Pipeline

```
       prompt:                 ┌──────────────────────────┐
"how to install cursor"  ───▶  │ generator/plan-with-claude│
                               │   (claude-sonnet-4-6)    │
                               └────────────┬─────────────┘
                                            │
                                            ▼
                                     plans/<id>.json
                                            │
                                            ▼
                              ┌────────────────────────────┐
                              │ audio/generate-tts          │  → public/audio/<id>.mp3
                              │ (ElevenLabs / OpenAI)       │
                              └────────────┬───────────────┘
                                            │
                                            ▼
                              ┌────────────────────────────┐
                              │ Remotion render             │  → out/<id>.mp4
                              │ (compositions/Reel)         │
                              └────────────────────────────┘
```

## Layout

```
video/
├─ bin/create.ts              # one-shot CLI
├─ plans/                     # *.json plans, one per video
├─ src/
│  ├─ Root.tsx                # auto-registers a Composition for every plan
│  ├─ index.ts                # registerRoot()
│  ├─ types/plan.ts           # Zod schema (the contract)
│  ├─ generator/              # Claude → plan JSON
│  ├─ compositions/Reel*      # plan-driven master composition
│  ├─ scenes/*Scene.tsx       # one renderer per scene type, all props-driven
│  ├─ components/             # reusable UI: bg, rings, cursor, mocks
│  ├─ theme/                  # design tokens (colors / fonts / easing)
│  ├─ audio/                  # TTS + caption alignment
│  ├─ automation/playwright/  # real browser recordings (optional)
│  └─ utils/animation.ts      # spring / lerp / bezier helpers
├─ package.json
├─ remotion.config.ts
└─ tsconfig.json
```

## Customising

- **Add a new reel:** drop a JSON file under `plans/`. The studio picks it up
  automatically and a Composition appears with that id.
- **Edit the AI's instructions:** `src/generator/system-prompt.ts`.
- **Tweak look-and-feel:** `src/theme/{colors,typography,easing}.ts`.
- **New scene type:** add a Zod variant to `src/types/plan.ts`, a renderer
  under `src/scenes/`, and wire it in `compositions/ReelComposition.tsx`.

## Languages

`meta.language: "he"` switches to the Heebo / Frank Ruhl Libre font pair,
flips captions to RTL, and tells ElevenLabs to use Hebrew. English is the
default.

## Recording real browser footage (optional)

Default scenes use pixel-perfect React mockups so the demo never breaks when
external sites change. To use real recordings instead:

```bash
npm run record:browser
```

…then set `content.kind` to `"recording"` with the file path in your plan.
